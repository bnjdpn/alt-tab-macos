# Free Fork Transition Notes

This fork keeps the upstream scheduling files in the Xcode project for source
compatibility, but the transition manager is intentionally inert.

- There is no paid tier.
- There is no trial period.
- There are no checkout, account, or license activation flows.
- Former premium-feature checks resolve as available.

If these files are removed later, delete the corresponding Xcode project
references at the same time.
